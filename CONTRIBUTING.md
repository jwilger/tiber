# Contributing

All changes are made through pull requests. Use Conventional Commit subjects
and include a non-empty commit body explaining the change.

Use the pinned Node.js and npm versions. Run `npm run verify` before submitting
a pull request.

Release versions are managed by release-please. Do not edit package versions,
create release tags, or publish from a workstation. Publishing occurs through
the protected GitHub Actions workflow with npm provenance.

Unless stated otherwise, contributions are submitted under both MIT and
Apache-2.0 terms.
