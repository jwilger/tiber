# Agentic systems

Inference is untrusted semantic input. Parse model output through a closed
schema and require deterministic policy to authorize every effect. A model may
request a tool, propose a plan, classify evidence, or report a blocker; it may
not execute effects, advance authoritative state, approve exceptions, or weaken
verification.

Keep assignments bounded by goal, role, context, token, cost, time,
concurrency, and effect budgets. Preserve stable cache prefixes and append
dynamic state as suffix messages. Compaction creates an explicit new epoch and
retains provenance to original artifacts.

Test product behavior with deterministic scripted model boundaries. Do not add
a live-provider CI runner without a separate product decision. Scrub secrets,
bound outputs, cancel owned work, and fail closed when authority evidence is
missing or malformed.
